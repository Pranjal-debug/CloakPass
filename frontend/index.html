Zero-Knowledge Verification

Security guarantees verified on-chain by Compact:

1. Merkle Membership Proof

Validates that your pass commitment is a member of the historic Merkle tree without disclosing leaf index.

2. Unlinkable Nullifier

Derives domain-tagged hash SHA256("cloakpass:nullify:" || secret), mathematically unlinkable to the commitment.

3. Controlled Disclosure

Only the nullifier and assertion boolean reach the public ledger via disclose() to prohibit double-use.

Midnight Dual-State Architecture

Strict separation between client-side private witnesses and public ledger state

COMPACT v0.26.0
Off-Chain Witnesses (100% Private)
  • pass_secret(): 32-byte secret credential; never broadcast to the network.
  • pass_salt(): Cryptographic blinding factor preventing rainbow-table discovery.
  • get_pass_path(): Merkle sibling route; your exact leaf position remains shielded.
  • Lace Account: Prover wallet public address is never tied to the redeemed pass.
Public Ledger State (Preprod On-Chain)
  • passCommitments: Historic Merkle tree root verifying valid pass membership.
  • usedNullifiers: Single-use nullifiers published to prevent double-spending.
  • totalIssued & totalRedeemed: Verifiable public counter metrics.
  • organizerPk: Authority public key sealing gate configuration.
