🔒 Zero-Knowledge Gate Verification Engine

How Midnight protects your identity during redemption:

1. Merkle Membership Proof

Proves checkRoot(merkleTreePathRoot(path)) == true using private witness without disclosing which leaf index you hold.

2. Unlinkable Nullifier Derivation

Computes SHA256("cloakpass:nullify:" || secret). This hash is mathematically independent from the commitment leaf.

3. Controlled Boundary via disclose()

Only the nullifier and the boolean assertion reach the on-chain ledger to prevent double-spending.
